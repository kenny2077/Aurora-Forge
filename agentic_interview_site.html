Run a day for real

Each folder has a ticket-style README, starter code, and a failing test suite you make pass with an AI assistant.

# Python days
cd days/Day6_Concurrency_Race && python3 -m pytest -q
# TypeScript days (Node 24 runs .ts natively)
cd days/Day7_CSV_Tokenizer_TS && node --test
# drive any day as a live mock in the terminal
python3 interview.py Day2_AmbiguousSpec

This page and interview.py are the spoiler-free mode: only the vague prompt, with hints when you ask. Days 1 to 20 were critic-gated to at least 8/10 on difficulty, solvability and learning value; days 21 to 35 are self-verified. Every starter fails for its stated reason, and every reference solution passes.
