# Sources — what this program is based on

Reporting on the AI-assisted / "vibe coding" interview shift, used to design the drills.

**How to read these:** they are secondary reporting and candidate write-ups, not company policy
documents. Meta's AI-enabled coding interview is the best-documented case; Google's is described as
Gemini-assisted formats tested for selected SWE interviews, so treat it as a pilot in progress
rather than a completed, company-wide switch. The drills are built on the *scoring shift* every
source agrees on, which holds regardless of how far any one rollout has gone.

- [Google's AI-Assisted Coding Interview (2026 Guide) — Exponent](https://www.tryexponent.com/blog/google-ai-coding-interview)
  — the three new rounds (code comprehension, technical design, open-ended), the "human-led,
  AI-assisted" framing, and the real L3 vague-problem anecdote that Day 2 is modeled on.
- [How to use AI in Meta's AI-assisted coding interview (real prompts & examples) — interviewing.io](https://interviewing.io/blog/how-to-use-ai-in-meta-s-ai-assisted-coding-interview-with-real-prompts-and-examples)
  — the four-phase workflow (understand → targeted AI → human review → test), prompt specificity,
  and multi-file/project-style challenges (Day 4).
- [Google Coding Interviews in 2026: What Changed — Levelop](https://levelop.dev/blog/google-coding-interviews-in-2026-what-changed-and-what-didnt)
- [Google's AI Interview Policy Explained — AceRound](https://www.aceround.app/blog/google-ai-interview-policy/)
- [AI-Assisted Coding Interviews (how to prepare) — IGotAnOffer](https://igotanoffer.com/en/advice/ai-assisted-coding-interview)
- [AI-Assisted Coding Interviews: What Gets Scored Now — Formation](https://formation.dev/blog/ai-assisted-coding-interviews)

## The through-line
Every source converges on the same point: the interview now scores **judgment, verification, and
ownership**, not code recall. Candidates fail by over-relying on AI without demonstrating their own
understanding. This program forces the opposite habit every single day.
